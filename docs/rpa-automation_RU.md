# RPA Автоматизация

DolfPower включает в себя мощный движок **Remote Process Automation (RPA)**, который позволяет выполнять сложные многоэтапные браузерные задачи без написания кода.

## Типы действий

RPA-движок поддерживает широкий спектр гуманизированных действий:
- **Навигация**: Переход на указанные URL.
- **Взаимодействие**: Клики, ввод текста, наведение (hover), выбор (select) и нажатия клавиш.
- **Гуманизированные движения**: Движения мыши следуют по кривым Безье с рандомизированной скоростью для обхода систем детекции ботов.
- **Гуманизированный ввод**: Симуляция реального набора текста с переменными задержками и имитацией исправления "опечаток".
- **Ожидания и условия**: Фиксированные задержки или ожидание появления специфических элементов/условий.
- **Скриншоты**: Захват состояния страницы для логирования или анализа.
- **Управление переменными**: Хранение и повторное использование значений между этапами.

## Генерация сценариев

Вы можете создавать RPA-сценарии тремя способами:
1. **Ручной конструктор**: Добавление и настройка действий через интерфейс.
2. **Генерация через Jarvis**: Опишите задачу на обычном языке, и Jarvis сам составит JSON-сценарий.
3. **Запись**: Используйте встроенный рекордер, чтобы записать свои действия и превратить их в RPA-сценарий.

## Движок гуманизации

Каждое автоматизированное действие проходит через слой гуманизации:
- **Кривые Безье**: Никаких прямых линий; движения выглядят так, будто их совершает реальный человек.
- **Дрожание (Jitter)**: Едва заметные случайные движения курсора во время ожидания.
- **Симуляция фокуса**: Правильная установка фокуса и нажатия на интерактивные элементы.

## Планирование задач

- **Массовый запуск**: Запуск сценария на десятках профилей одновременно.
- **Планирование**: Установка точного времени запуска задачи.
- **Периодические задачи**: Повторение сценариев каждые N минут или часов.
- **Поддержка Cron**: Использование стандартных выражений Cron для сложного планирования (например, «Запускать каждый понедельник в 9:00»).
