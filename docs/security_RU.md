# Безопасность и Приватность

DolfPower построен на локальной архитектуре «Zero Trust» (нулевого доверия). Мы считаем, что ваши цифровые личности должны быть доступны только вам.

## Шифрование данных

### Мастер-пароль
При инициализации DolfPower вы создаете Мастер-пароль.
- Этот пароль используется для генерации 256-битного ключа AES через PBKDF2 с 100 000 итераций.
- **Ничего не хранится в открытом виде**: Пароли прокси, секреты TOTP, API-ключи Jarvis и куки зашифрованы.
- Мастер-ключ хранится только в **оперативной памяти (RAM)** и удаляется при выходе из системы или перезагрузке приложения.

### Аппаратная привязка (Fallback)
Для начальной настройки и базовых конфигураций DolfPower использует уникальный ключ, производный от аппаратных идентификаторов вашей машины (MAC-адрес, данные процессора, информация об ОС). Это гарантирует, что даже если файл базы данных будет украден, его нельзя будет расшифровать на другом компьютере без вашего Мастер-пароля.

## Двухфакторная аутентификация (2FA)

DolfPower поддерживает стандарт TOTP (Google Authenticator и др.) для двух целей:
1. **Доступ к приложению**: Защита всей панели управления DolfPower.
2. **2FA для профилей**: Управление и генерация кодов для ваших социальных сетей или крипто-аккаунтов прямо в интерфейсе управления профилями.

## Песочница Telegram (Sandbox)

Наша интеграция с Telegram использует модель «песочницы»:
- **Подтверждение через PIN**: Опасные действия (удаление, запуск скрипта, обновление конфига) требуют ввода 6-значного PIN-кода, который Jarvis генерирует и отправляет в ваш чат.
- **Очистка сессии**: Выход из системы аннулирует все ожидающие PIN-коды и токены безопасности.

## Функции приватности

- **Изолированные UserDataDirs**: Каждый профиль имеет свой собственный каталог на диске, что исключает возможность обмена кэшем или данными сессии между экземплярами Chromium.
- **Рандомизация отпечатка**: Каждый профиль использует уникальный `fingerprint_seed` для генерации согласованных, но отличных друг от друга аппаратных сигнатур.
- **Никакой облачной синхронизации**: По умолчанию все ваши данные остаются на вашей машине. Вы сами контролируете свои бэкапы.
