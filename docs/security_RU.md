# Безопасность и Приватность

DolfPower построен на локальной архитектуре «Zero Trust» (нулевого доверия). Мы считаем, что ваши цифровые личности должны быть доступны только вам.

## Шифрование данных

### Мастер-пароль
При инициализации DolfPower вы создаете Мастер-пароль.
- Этот пароль используется для генерации 256-битного ключа AES через PBKDF2 с 100 000 итераций.
- **Ничего не хранится в открытом виде**: Пароли прокси, секреты TOTP, API-ключи Jarvis и куки зашифрованы.
- Мастер-ключ хранится только в **оперативной памяти (RAM)** и удаляется при выходе из системы или перезагрузке приложения.

### Аппаратная привязка (Fallback)
Для начальной настройки и базовых конфигураций DolfPower использует уникальный ключ, производный от аппаратных идентификаторов вашей машины (MAC-адрес, данные процессора, информация об ОС). Это гарантирует, что даже если файл базы данных будет украден, его нельзя будет расшифровать на другом компьютере без вашего Мастер-пароля.

## Двухфакторная аутентификация (2FA)

DolfPower поддерживает стандарт TOTP (Google Authenticator и др.) для двух целей:
1. **Доступ к приложению**: Защита всей панели управления DolfPower.
2. **2FA для профилей**: Управление и генерация кодов для ваших социальных сетей или крипто-аккаунтов прямо в интерфейсе управления профилями.

## Песочница Telegram (Sandbox)

Наша интеграция с Telegram использует модель «песочницы»:
- **Подтверждение через PIN**: Опасные действия (удаление, запуск скрипта, обновление конфига) требуют ввода 6-значного PIN-кода, который Jarvis генерирует и отправляет в ваш чат.
- **Очистка сессии**: Выход из системы аннулирует все ожидающие PIN-коды и токены безопасности.

## Функции приватности

- **Изолированные UserDataDirs**: Каждый профиль имеет свой собственный каталог на диске, что исключает возможность обмена кэшем или данными сессии между экземплярами Chromium.
- **Рандомизация отпечатка**: Каждый профиль использует уникальный `fingerprint_seed` для генерации согласованных, но отличных друг от друга аппаратных сигнатур.
- **Никакой облачной синхронизации**: По умолчанию все ваши данные остаются на вашей машине. Вы сами контролируете свои бэкапы.

## Расширенные функции безопасности

### Служба безопасности кошелька
DolfPower обеспечивает специализированную защиту данных криптовалютных кошельков:
- **Зашифрованное хранение**: Seed-фразу, приватные ключи и метаданные кошелька шифруются с использованием мастер-ключа, полученного из вашего Мастер-пароля
- **Локальная-only архитектура**: Все данные кошелька хранятся исключительно на вашем локальном компьютере в зашифрованном хранилище
- **Функция безопасного стирания**: Возможность экстренного стирания, которая перезаписывает хранилище кошелька случайными данными перед удалением
- **Валидация ввода**: Встроенная проверка seed-фраз (формат BIP39), приватных ключей и адресов кошельков для предотвращения случайного раскрытия неверных данных
- **Зависимость от мастер-ключа**: Операции с кошельком требуют успешного входа пользователя для доступа к мастер-ключу шифрования

### Служба защиты буфера обмена
Автоматическая защита от кражи конфиденциальных данных из буфера обмена:
- **Распознавание паттернов**: Обнаружение потенциально конфиденциальных данных, включая seed-фразу (12/24 слова), приватные ключи, адреса кошельков, API-ключи и надежные пароли
- **Отложенная очистка**: Автоматическая очистка обнаруженного конфиденциального содержимого буфера обмена после настраиваемой задержки (по умолчанию 10 секунд)
- **Отслеживание истории**: Ведение истории недавних содержимых буфера обмена для avoidance повторных проверок одних и тех же данных
- **Ручная очистка**: Предоставление возможности немедленной ручной очистки для экстренных ситуаций

### Служба защиты экрана
Смягчение последствий захвата экрана и записи конфиденциальной информации:
- **Мониторинг видимости**: Обнаружение моментов, когда окно приложения скрыто или свернуто, что может указывать на попытку захвата экрана
- **Предупреждающие наложения**: Отображение полупрозрачных предупреждающих наложений при обнаружении потенциального захвата экрана
- **Защита на уровне элементов**: Возможность защиты конкретных DOM-элементов с визуальными индикаторами и отслеживанием позиции
- **Подход лучших усилий**: Реализация методов защиты на уровне браузера с признанием ограничений на уровне ОС

### Служба экстренной блокировки
Механизмы мгновенной защиты при imminентных угрозах:
- **Однокликовая активация**: Мгновенная защита всех конфиденциальных данных одним действием
- **Всестороннее стирание данных**:
  - Стирание зашифрованного хранилища кошелька из хранилища
  - Немедленная очистка содержимого буфера обмена
  - Остановка мониторинга буфера обмена
  - Активация защиты экрана
  - Очистка мастер-ключа шифрования из памяти
- **Блокировка по времени**: Автоматический сброс через настраиваемый период (по умолчанию 5 минут) с требованием повторной аутентификации пользователя
- **Ручной триггер**: Может быть активирован через паническую кнопку или комбинацию клавиш в интерфейсе

### Служба безопасного ввода
Защищенный ввод конфиденциальных учетных данных для противодействия кейлоггерам:
- **Безопасное наложение**: Представление поля ввода в безопасном наложении, которое предотвращает доступ со стороны других приложений
- **Маскировка символов**: Показ введенных символов brevemente перед их маскировкой для защиты от просмотра через плечо
- **Защита фокуса**: Предотвращение потери фокуса для поддержания безопасности ввода
- **Обработка Escape**: Позволяет отмену с клавишей Escape и отправку с клавишей Enter
- **Очистка памяти**: Очистка значения ввода немедленно после отправки

### Расширенный менеджер прокси
Интеллектуальное управление прокси с мониторингом состояния:
- **Метрики производительности**: Отслеживание успешности, латентности и надежности для каждого прокси
- **Интеллектуальная ротация**: Автоматический выбор лучшего прокси на основе оценки производительности
- **Мониторинг состояния**: Периодическое тестирование всех прокси и обновление их метрик
- **Обнаружение сбоев**: Помеча прокси как неактивные после последовательных сбоев
- **Географическая фильтрация**: Поддержка выбора прокси по стране, когда географические данные доступны
- **Интеграция бесплатных прокси**: Автоматическое получение и тестирование прокси из общедоступных источников

### Служба решения каптч
Автоматическое решение различных типов каптч с локальным хранением API-ключей:
- **Поддержка множества провайдеров**: Совместимость с сервисами 2captcha, Anti-Captcha, DeathByCaptcha и ImgType
- **Шифрование учетных данных**: Хранение API-ключей локально с использованием того же шифрования, что и для других конфиденциальных данных
- **Множество типов каптч**: Обработка изображений-каптч, reCAPTCHA, hCaptcha, FunCaptcha и Geetest
- **Локальная конфигурация**: Все настройки хранятся локально на вашем компьютере без внешних зависимостей
- **Функциональность тестирования**: Включает возможности тестирования сервиса для проверки конфигурации

### Служба версионирования профилей
Возможности создания снимков и отката для браузерных профилей:
- **Снимки версий**: Создание полных резервных копий конфигураций профиля и отпечатков пальцев
- **Описание изменений**: Возможность добавления описательных заметок к каждой версии для лучшего отслеживания
- **Резервное копирование в файловую систему**: Оptionальное сохранение версий в локальную файловую систему для дополнительной избыточности
- **Хранение в базе данных**: Поддержание метаданных версий в локальной базе данных SQLite
- **Выборочный откат**: Возможность восстановления профилей в любое предыдущее состояние версии
- **Опции очистки**: Предоставление удаления версий для управления объемом памяти

### Служба мониторинга угроз
Проактивное обнаружение локальных угроз безопасности:
- **Мониторинг процессов**: Сканирование на известные вредоносные процессы (кейлоггеры, stealers, RATs и т.д.)
- **Проверка целостности файловой системы**: Проверка отслеживаемых директорий на подозрительные файлы
- **Настраиваемое сканирование**: Регулируемые интервалы сканирования и чувствительность обнаружения
- **Автоматический ответ**: Может запускать экстренную блокировку автоматически при обнаружении высокоуровневых угроз
- **Локальный анализ**: Все обнаружение угроз выполняется локально без внешней отчетности
- **Ручная настройка**: Регулируемая чувствительность и отслеживаемые директории через конфигурацию
