# Основные возможности

DolfPower предлагает набор продвинутых функций, предназначенных для полного контроля над вашими цифровыми личностями.

## 1. Изоляция браузерных профилей
Каждый профиль в DolfPower — это полностью изолированная среда.
- **Раздельные куки и кэш**: Данные никогда не утекают между сессиями.
- **Изолированное хранилище**: LocalStorage и IndexedDB уникальны для каждого профиля.
- **Уникальные отпечатки**: Каждый профиль выглядит для веб-сайтов как отдельное физическое устройство.

## 2. Продвинутая подмена отпечатков (Fingerprint Spoofing)
Мы настраиваем более 40 аппаратных и программных параметров, чтобы сделать ваши профили уникальными:
- **Canvas и WebGL**: Добавление шума для предотвращения аппаратного отслеживания.
- **Audio Context**: Подмена сигнатур аудио-оборудования.
- **Экран и разрешение**: Настраиваемые разрешения, глубина цвета и соотношение пикселей.
- **Свойства Navigator**: User Agent, платформа, языки, количество ядер процессора (hardware concurrency) и объем оперативной памяти.
- **Таймзона и Геолокация**: Автоматическая синхронизация на основе прокси или ручная настройка.
- **WebRTC**: Режимы для реального IP, его отключения или предоставления "измененного" IP, соответствующего вашему прокси.

## 3. Интегрированное управление прокси
- Поддержка протоколов **HTTP, HTTPS и SOCKS5**.
- **Тестирование прокси**: Проверка скорости и стабильности соединения перед запуском.
- **Проверка IP-информации**: Подробные данные об IP, стране, городе и провайдере.
- **Поиск бесплатных прокси**: Встроенный инструмент для сбора и тестирования прокси из публичных списков (GeoNode, ProxyScrape).

## 4. Управление расширениями и закладками
- **Глобальные расширения**: Автоматическая установка выбранных расширений (например, uBlock или MetaMask) в каждый новый профиль.
- **Общие закладки**: Поддержание единого набора закладок для всей вашей фермы.

## 5. Организация групп
Организуйте сотни профилей в группы с настраиваемыми цветами и описаниями для удобства управления.

## 6. Расширенные функции безопасности
DolfPower включает комплексные меры безопасности для защиты ваших ключей криптовалютных кошельков и конфиденциальных данных:
- **Служба безопасности кошелька**: Зашифрованное локальное хранение для seed-фраз, приватных ключей и метаданных кошелька с функцией безопасного стирания
- **Защита буфера обмена**: Автоматическое обнаружение и очистка конфиденциального содержимого буфера обмена (seed-фразу, приватные ключи, API-ключи)
- **Защита экрана**: Смягчение последствий захвата экрана и записи конфиденциальной информации
- **Экстренная блокировка**: Однокликовая активация для мгновенной защиты всех конфиденциальных данных в случае угрозы
- **Безопасный ввод**: Защищенный ввод конфиденциальных учетных данных для противодействия кейлоггерам
- **Расширенный менеджер прокси**: Интеллектуальное управление прокси с мониторингом состояния, метриками производительности и автоматической ротацией
- **Служба решения каптч**: Автоматическое решение различных типов каптч с локальным хранением API-ключей
- **Версионирование профилей**: Возможности создания снимков и отката для браузерных профилей
- **Мониторинг угроз**: Проактивное обнаружение локальных угроз безопасности с автоматическим реагированием

## 7. Миграция из локальных браузеров
Бесшовный переход из других антидетект-браузеров в DolfPower.
- **Автоматическое обнаружение**: Автоматически находит установленные браузеры Dolphin Anty, AdsPower, GoLogin, Octo, Multilogin и др.
- **Импорт в один клик**: Перенос профилей со всеми данными (куки, хранилище, отпечатки) напрямую в DolfPower.
- **Глубокое сканирование**: Поиск данных профилей в пользовательских путях для менее распространенных или портативных версий браузеров.
