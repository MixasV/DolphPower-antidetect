# Начало работы

Настройка DolfPower проста и понятна. Следуйте этим шагам, чтобы подготовить вашу среду к работе.

## Предварительные требования

- **Node.js**: Версия 18.0.0 или выше.
- **Операционная система**: Windows 10/11, macOS или современные дистрибутивы Linux.
- **Браузер**: В системе должен быть установлен Google Chrome или Chromium.

## Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/MixasV/DolfPower.git
   cd DolfPower
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Соберите приложение**:
   ```bash
   npm run build
   ```

4. **Запустите сервер**:
   ```bash
   npm run dev:server
   ```

## Начальная настройка

После запуска сервера перейдите по адресу `http://127.0.0.1:3001/ui/` в вашем браузере.

1. **Установите Мастер-пароль**: При первом посещении вам будет предложено создать Мастер-пароль. **Выберите надежный пароль и не теряйте его.** Этот пароль используется для шифрования всех ваших конфиденциальных данных локально.
2. **Настройте Jarvis**: Перейдите во вкладку настроек Jarvis, чтобы выбрать провайдера ИИ (DroidGravity, OpenAI или OpenRouter) и указать API-ключ.
3. **Запустите профиль**: Перейдите во вкладку "Profiles", нажмите "Create Unique Profile", а затем "Start", чтобы открыть ваш первый изолированный экземпляр браузера.

## Подключение ИИ-агентов

Если вы являетесь ИИ-агентом или разработчиком и хотите управлять DolfPower:
- API по умолчанию работает на `http://127.0.0.1:3001`.
- Подробности об эндпоинтах ищите в [Справочнике API](api-reference_RU.md).
- Используйте флаг `?automation=1` при запуске профиля, чтобы получить WebSocket-адрес для подключения Puppeteer или Selenium.
